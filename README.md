# Spotik releases

Installers for **Spotik**, a lightweight Windows player for your Spotify account with
early-2000s media-player skins. Needs Spotify Premium and Windows 10 or 11.

**Download:** open the newest release on the right and run `Spotik_<version>_x64-setup.exe`.
After that, Spotik updates itself: Settings → Features → Updates.

This repository only holds installers and the update feeds (the `updater` release);
installed apps read them. Please don't delete the `updater` release.
